# Day 07 — CSS Landing Page

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A fully styled product landing page for a fictional coding
platform called CodeFlow. Built with pure HTML and CSS.

## How to view
Open `index.html` in your browser or enable GitHub Pages.

## Features
- Sticky navbar
- Hero section with code block visual
- Stats bar
- Features grid
- Courses section
- Testimonials
- Call to action section
- Fully responsive layout
